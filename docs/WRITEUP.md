# Brain Tumor MRI Classification

**Intended user.** A junior radiologist reviewing brain MRI images who wants an educational second-look visualization—not an automated diagnostic or screening system.

**Problem.** Brain MRI interpretation requires specialist expertise. We explored whether transfer learning can classify MRI images into four dataset labels—glioma, meningioma, no tumor, and pituitary tumor—and expose model errors for discussion.

**What we built and added.** We built a ResNet50 image-classification pipeline with ImageNet preprocessing, a frozen-backbone transfer-learning stage, controlled fine-tuning, saved Keras checkpoints, an inference interface, and optional Grad-CAM overlays. Our contribution is packaging the work as a reproducible, judge-friendly project: dataset checks and split preparation, consistent class mappings, a held-out evaluation with per-class metrics and error examples, and a Colab notebook that compares against a simple majority-class baseline. Grad-CAM is included only as a qualitative visualization.

**Results.** On the provided 1,600-image Testing split (400 images per class), the repository's validation-selected ResNet50 checkpoint reached **87.1% accuracy** and **0.868 macro F1**. The majority-class baseline is **25.0% accuracy** on this balanced test set (a constant prediction gets 400 of 1,600 correct). Glioma recall was 73.0%, meningioma recall 77.8%, no-tumor recall 99.8%, and pituitary recall 98.0%. The checkpoint was selected using validation loss, not test results. This result came from a **partial training run**; the configured full training schedule was not completed. The Colab notebook can train a separate short fallback model when repository weights are unavailable; its results must be measured independently and are not represented by the result above. These are experimental measurements, not evidence of clinical performance.

**Where it fails.** The confusion matrix shows glioma is the main weakness: 65 of 400 glioma images were predicted as meningioma and 38 as no tumor. Meningioma was also predicted as no tumor for 40 of 400 images. A saved example, `Te-gl_1`, is a glioma image predicted as no tumor with 86.7% model confidence—an especially important reminder that confident output can still be wrong. See the [evaluation report](../results/reports/REAL_EVALUATION_REPORT.md) and [Grad-CAM example](../results/my_first_test/Te-gl_1_overlay.png) for supporting artifacts.

**Sources.** Dataset: Masoud Nickparvar, [Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset), version 2, CC BY 4.0. Backbone: [Keras ResNet50](https://keras.io/api/applications/resnet/). Visualization method: Selvaraju et al., [Grad-CAM](https://arxiv.org/abs/1610.02391).

**Limitations and medical disclaimer.** The dataset does not provide patient identifiers, so patient-independent separation cannot be verified. The audit flagged 2,740 cross-split perceptual near-match candidates; these are not confirmed duplicates but remain unresolved. The model was not externally or clinically validated, and this experiment does not establish safety, fairness, or real-world generalization. **This is an educational prototype, not a medical device or diagnostic tool. Do not use it for screening, diagnosis, treatment, triage, or patient-care decisions. Medical decisions must be made by qualified clinicians using appropriate clinical evidence.**
